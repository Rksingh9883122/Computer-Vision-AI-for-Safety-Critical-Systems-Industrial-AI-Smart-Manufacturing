# Safety Observation Detection using AI Vision & Data Analytics

## 📌 Project Overview

This project implements an **AI‑driven safety observation detection system** using **computer vision cameras and data analytics** to identify unsafe acts, unsafe conditions, and near‑miss events in industrial environments. The goal is to enable **proactive safety management**, reduce incidents, and support **data‑driven HSE decision‑making**.

***

## 🎯 Objectives

*   Automate safety observations using AI vision cameras
*   Detect unsafe behaviors and site conditions in real time
*   Reduce reliance on manual safety inspections
*   Provide actionable safety insights through analytics
*   Improve overall workplace safety performance

***

## 🧠 Key Features

*   Real‑time video analysis using AI vision models
*   Detection of unsafe acts and unsafe conditions
*   PPE compliance monitoring
*   Event logging and safety classification
*   Safety trend analysis and visualization
*   Scalable architecture for multi‑site deployment

***

## 🔍 Safety Use Cases

*   PPE non‑compliance detection (helmet, vest)
*   Unsafe posture and manual handling
*   Working at height violations
*   Restricted / hazardous zone intrusion
*   Vehicle–pedestrian interaction risks
*   Housekeeping and slip/trip hazards
*   Near‑miss identification
